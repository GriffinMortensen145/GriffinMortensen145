# Realmwright

**Play:** https://griffinmortensen145.github.io/GriffinMortensen145/

You rule a small medieval settlement on a procedurally generated continent. Grow it into a kingdom through farming, building, trade, diplomacy and war. Three to six rival realms run the same economy and make their own decisions, so they found cities, form alliances and fight each other whether or not you're involved. The chronicle in the corner reports what's happening across the continent.

## How it plays

- **City building.** Farms, houses, lumber camps, quarries, iron and gold mines, markets, libraries and barracks go on tiles inside your borders. Cities grow from village to town to castle and can be walled.
- **Economy.** Food, wood, stone, iron, gold and population. Buildings need workers, so houses matter as much as production.
- **Expansion.** Found new cities to claim land. Scouts explore the wilderness and make contact with other realms.
- **Diplomacy.** Alliances, peace, trade routes, gifts, and buying or selling resources. Allies expect you to join their wars.
- **Battles.** Command battles in real time or auto-resolve them. Infantry beat cavalry, cavalry beat archers and siege, archers beat infantry, and siege engines break walls. Formations: line, wedge and block.
- **Research.** Four branches (agriculture, construction, military, economics) across three ages: Settlement, Expansion and Empire.
- **Victory.** Conquest (60% of cities), economy (25,000 gold), diplomacy (a year allied with every surviving realm) or knowledge (the Enlightenment). A rival can win the same way.

## Controls

| Input | Action |
| --- | --- |
| Drag, WASD | Pan the map |
| Scroll | Zoom |
| Click | Select a tile, city or army |
| Right-click | Move the selected army, or attack an enemy city |
| Space | Pause |
| T / G / V | Research, realms, victory progress |
| In battle: drag | Select companies |
| In battle: right-click | Move or attack |
| In battle: Q, C, H | Select all, charge, hold |
| In battle: 1, 2, 3 | Line, wedge, block formation |

Every game uses a new seed. Type a seed on the title screen to replay a specific continent. The whole game is one file, `index.html`, with no build step.
